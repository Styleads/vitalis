# Vitalis Frontend

React + TypeScript + Vite hospital resource-management simulator.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

This version uses local mock data and React state. Backend/WebSocket integration can be added later.

The hero background intentionally references `/hospital-bg.jpg`; if that image is not present, the gradient still keeps the layout usable.
